Academic information assistant · Student project

N8n Rag Agent

An experimental question-answering assistant designed to help users find information in a supplied CSE-1 Faculty Responsibility Knowledge Base for Odd Semester 2026–27.

What it does

The prototype uses a retrieval-augmented generation (RAG) workflow to locate relevant information in the provided knowledge-base document and generate answers to questions about faculty responsibilities and coordinators.

Answers depend on the source document and may not reflect later changes. Please confirm important or time-sensitive information with the college or the relevant faculty member.

Project status and affiliation

This is an independent educational project. It is not an official ABES Engineering College website or an official college service, and it should not be presented as endorsed by the college unless authorization has been granted.
